# NekoTracking
NekoTrackingは、MediaPipeを使用してリアルタイムで体の各パーツの位置を取得できるTurboWarpのカスタム拡張機能です。
# 使い方
1. [TurboWarp](https://turbowarp.org/editor)にアクセスします。
2. 画面左下の「拡張機能を追加」ボタンをクリックします。
3. 「カスタム拡張機能」を探してクリックします。
4. 「ファイル」タブを開きます。
5. 使いたいNekoTrackingをアップロードします。
6. 「サンドボックス無しで実行する」にチェックを入れ、「読み込む」をクリックします。  
これで完了です!
# ファイルの説明
- `NekoTrackingFull.js`: すべてのNekoTrackingを1拡張機能にまとめたものです。
- `NekoTrackingFace.js`: 顔の各パーツ/目と口の開き具合を取得できるNekoTrackingです。
- `NekoTrackingHand.js`: 手の各パーツの位置を取得できるNekoTrackingです。
- `NekoTrackingBody.js`: 体の各パーツの位置を取得できるNekoTrackingです。
